# AI Content Studio Skill

## Capabilities
- **Script Rewriter**: Convert novels/outlines into formatted drama screenplays
- **Character & Scene Extractor**: Extract characters and scenes from scripts with smart dedup
- **Storyboard Breaker**: Break scripts into detailed shot sequences (10-15s per shot)
- **Voice Assigner**: Suggest matching AI voices for each character
- **Image Prompt Generator**: Generate image prompts for characters, scenes, and grid layouts

## Workflow
1. Create a new drama project in Content Studio
2. Add episodes and paste novel/outline content
3. Use AI agents to process: Rewrite → Extract → Storyboard
4. Review and edit characters, scenes, and storyboards
5. Export to markdown, text, DOCX, or Google Drive

## API Endpoints
- UI: `/content-studio`
- Settings: `/content-studio/settings`
- API: `/api/v1/studio/*`

## When to use
Use this extension when the user wants to:
- Write or format drama/novel scripts
- Extract characters or scenes from text
- Create shot breakdowns from screenplays
- Generate AI image prompts for production
- Export scripts to various formats
